1. Application is deployed with Restricted Pod Security Standard hardening.
2. Check the namespace security labels:
   kubectl get ns {{ .Values.namespace.name | default .Release.Namespace }} --show-labels
3. Verify running pods and securityContext:
   kubectl get pods -n {{ .Values.namespace.name | default .Release.Namespace }} -l {{ include "k8s_security_enhancement.selectorLabels" . }}
4. Check NetworkPolicy status:
   kubectl get netpol -n {{ .Values.namespace.name | default .Release.Namespace }}
5. Run Helm template tests:
   helm test {{ .Release.Name }} -n {{ .Values.namespace.name | default .Release.Namespace }}
